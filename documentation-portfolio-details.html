Features

Core functionalities

Eight capabilities built to serve product teams and end-users alike.

Centralized Hub

A single source of truth for all product documentation — guides, references, and release notes in one place.

Algolia Search

Fast, accurate full-text search powered by Algolia — users find what they need in seconds, not minutes.

Multi-language Support

Content available in multiple languages to serve a global user base without maintaining separate sites.

Clear Content Structure

Categories, tags, and intuitive navigation make it easy to browse and discover relevant content.

Markdown-based Authoring

Content is written in Markdown — fast to create, easy to review, and seamless to collaborate on via GitHub.

Continuous Deployment

Every merge to the main branch triggers an automatic Netlify deployment — zero manual publishing steps.

Version Control

Content lives in GitHub — full history, branching, and pull request reviews keep documentation in sync with the product.

Fully Responsive

Optimised layout for desktop, tablet, and mobile — documentation is accessible wherever users are working.
